來源與說明

AI Resource Hub

統一入口，整合 Astra 3D Resource Hub 與 Codex Skills Hub 為同一套視覺、導覽、搜尋、主題、收藏框架。

  • 保留兩份獨立 JSON：data/astra-resources.json 與 data/codex-skills.json，不硬合併 schema
  • 共用 layout/header/nav/search/theme/favorites/RWD/card基礎，專用欄位各自保留
  • 全站搜尋標記來源 [Astra 3D] / [Codex Skill]
  • 收藏使用 namespaced keys：ai-resource-hub:astra:favorites, ai-resource-hub:codex:favorites, ai-resource-hub:codex:installed
  • 安全：網站不執行 Shell，安裝 Skill 僅複製指令，已安裝僅為手動標記

Astra 模組

資料來源：TripoGrowthLab/awesome-astra-prompts 與自行整理，包含 Blender、CAD DXF 解析、牆體提取、容差檢查、BIM、Three.js 等。

新增方式：編輯 data/astra-resources.json，必填 id/title/category/description，其餘留空，禁止捏造 URL

Codex 模組

資料主要整理自 composio-community/awesome-codex-skills，包含 10 個已驗證 Skill，風險依證據判定，未確認用 null

新增方式：編輯 data/codex-skills.json，依 SKILL.md 檢查 scripts/references/network/gitWrite/deleteFiles

安全限制：不得加入 analytics、tracking script、遠端可執行 script、自動安裝、API Key 儲存

舊站遷移

舊站 astra-3d-resource-hub 與 codex-skills-hub 在新站驗收完成後，改為輕量 landing + 導向 /ai-resource-hub/?hub=astra / ?hub=codex，保留人工點擊入口，不立即 JS redirect

localStorage 跨舊新站同 origin 可自動遷移一次，若跨瀏覽器或已清除需手動
